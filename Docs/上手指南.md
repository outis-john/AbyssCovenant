# 上手指南：从零到两个人联机互相射击

目标：做完这份指南，你可以在电脑上开两个游戏窗口，两个角色互相开枪、扣血，也就是路线图第 2 阶段的关卡。

遇到任何报错，**截图发给 Claude**，并说明做到了第几步。

---

## 第 0 步：先装好这些软件

| 软件 | 下载 | 注意 |
| --- | --- | --- |
| Epic Games Launcher | epicgames.com | 登录后在 "Unreal Engine → 库" 里安装最新的 UE 5.x |
| Visual Studio 2022 Community | visualstudio.microsoft.com | 安装时**一定要勾选 "使用 C++ 的游戏开发"**，否则 C++ 编译不了 |
| GitHub Desktop | desktop.github.com | 用你的 GitHub 账号登录 |

电脑要求：独立显卡，硬盘至少留 100 GB（引擎 + Visual Studio + 项目）。

---

## 第 1 步：建 GitHub 仓库，放进项目文件

1. 打开 GitHub Desktop → 左上角 **File → New repository**。
2. 填写：
   - Name：`AbyssCovenant`
   - Local path：选一个**路径里没有中文和空格**的文件夹，比如 `D:\Projects`
   - Git ignore：选 **None**（项目里已经带了 `.gitignore`）
3. 点 **Create repository**。现在 `D:\Projects\AbyssCovenant` 就是你的仓库文件夹。
4. 把 Claude 发给你的压缩包**解压到这个文件夹里**：右键压缩包 → 全部解压缩，**把目标路径改成 `D:\Projects\AbyssCovenant`**（Windows 默认会再多建一层同名文件夹，要删掉）。解压后应该是这样：
   ```
   D:\Projects\AbyssCovenant\
       AbyssCovenant.uproject
       Config\
       Source\
       Docs\
       README.md
       .gitignore
       .gitattributes
   ```
   注意不要多套一层文件夹（不要变成 `AbyssCovenant\AbyssCovenant\...`）。
5. 回到 GitHub Desktop，左边会出现一堆新文件。左下角 Summary 填 `初始项目`，点 **Commit to main**。
6. 点上方的 **Publish repository**，保持勾选 **Keep this code private**，点 Publish。

完成后在 github.com 上就能看到你的项目了。以后每做完一点，就在 GitHub Desktop 里 Commit 再 **Push origin**，相当于存档。

> 如果 GitHub Desktop 提示要初始化 **Git LFS**，点同意。蓝图和地图文件很大，要靠 LFS 管理。

---

## 第 2 步：打开项目（会自动编译 C++）

1. 在文件夹里**右键 `AbyssCovenant.uproject` → Switch Unreal Engine version**，选你装的版本，点 OK。
2. **双击** `AbyssCovenant.uproject`。
3. 弹出 "The following modules are missing or built with a different engine version… Would you like to rebuild them now?" → 点 **Yes**。
4. 等几分钟（第一次编译比较久），编辑器会自动打开。

**如果编译失败：**
1. 右键 `AbyssCovenant.uproject` → **Generate Visual Studio project files**。
2. 双击生成的 `AbyssCovenant.sln`，用 Visual Studio 打开。
3. 上方菜单 **生成 → 生成解决方案**。
4. 把下方 "错误列表" 里的报错截图发给 Claude。

---

## 第 3 步：加入第一人称模板的内容

1. 编辑器里打开 **Content Drawer**（左下角，或按 `Ctrl + 空格`）。
2. 点左上角 **+ Add → Add Feature or Content Pack**。
3. 选 **First Person**，点 **Add to Project**。
4. 打开模板自带的第一人称地图（在 Content Drawer 里找 `FirstPerson/Maps` 之类的文件夹，双击地图）。

---

## 第 4 步：设置 GameMode

1. Content Drawer 里右键 → **Blueprint Class** → 展开下面的 **All Classes**，搜索 `AbyssGameMode`，选中后点 Select。
2. 命名为 `BP_AbyssGameMode`，双击打开。
3. 右边 Details 里找到 **Default Pawn Class**，选模板的角色（一般叫 `BP_FirstPersonCharacter`）。点 Compile、Save。
4. 菜单 **Edit → Project Settings → Maps & Modes**：
   - **Default GameMode** 选 `BP_AbyssGameMode`
   - **Editor Startup Map** 和 **Game Default Map** 选第一人称地图

---

## 第 5 步：给角色装上我们的组件

1. 打开 `BP_FirstPersonCharacter`。
2. 左上角 Components 面板点 **+ Add**，依次搜索并添加：
   - `Abyss Health`
   - `Abyss Weapon`
   - `Abyss Psychic`
   - `Abyss Player Actions`
3. **接上开火：** 在 Event Graph 里找到模板的开火输入事件（一般叫 `IA_Shoot` 或 `Fire`），从 **Triggered** 引脚拉线，调用 `Abyss Weapon → Fire`。
   - 如果模板的开火逻辑在武器蓝图里，也是同样的思路：在开火事件里调用角色身上 Abyss Weapon 组件的 Fire。这一步截图给 Claude，可以帮你看怎么连。
4. **先用打印代替命中特效：**
   - 选中 `Abyss Weapon` 组件，在 Details 最下面 Events 里点 **On Hit Confirmed** 旁的 `+`，接一个 **Print String**，内容填 `命中！`。
   - 选中 `Abyss Health`，点 **On Health Changed** 的 `+`，接 Print String，把 New Health 连到 In String（会自动加转换节点）。
5. **配置灵能（可选，先测试用）：**
   - 选中 `Abyss Psychic`，Details 里 **Equipped Spells** 点 `+` 加 3 个：
     - 0：Form = Bolt，Element = Fire
     - 1：Form = Blast，Element = Void
     - 2：Form = Bolt，Element = Lightning，Modifiers 加一个 Split
   - Event Graph 里右键搜索 `1`（Keyboard Events → One），连到 `Abyss Psychic → Cast Spell`，Spell Index 填 0。`2`、`3` 同理填 1、2。
6. Compile、Save。

---

## 第 6 步：测试联机（关卡：两个人能互相射击）

1. 编辑器上方 Play 按钮旁边的 **⋮ 下拉菜单**：
   - **Number of Players** 设为 `2`
   - **Net Mode** 选 **Play As Listen Server**
2. 点 Play，会出现两个游戏窗口：一个是房主，一个是加入的玩家。
3. 用一个窗口瞄准另一个角色开枪：
   - 开枪的窗口出现 `命中！`
   - 两边都能看到血量下降
   - 血量打到 0 后不会再继续扣血（倒地动画还没做，所以角色暂时还站着）
   - 如果两个人都被打死，会触发全队阵亡、尝试回大厅。因为还没有大厅地图，会出现找不到地图的警告，这是正常的

**看到这些，第 2 阶段的关卡就过了。** 记得在 GitHub Desktop 里 Commit + Push。

> 打不中人？选中角色的 Mesh 和 Capsule，在 Collision 里把 **Visibility** 通道设为 **Block**。

---

## 之后：真正通过 Steam 和朋友联机

编辑器里的测试不走 Steam。和朋友真联机需要：
- 两台电脑登录**不同**的 Steam 账号，Steam 客户端开着
- 做一个大厅地图，用蓝图节点 **Create Session / Find Sessions / Join Session** 建房和加入

这是下一步，做到这里时告诉 Claude，会再给你一份详细步骤。

---

## 每个 C++ 系统在蓝图里怎么用

| 系统 | 在蓝图里用到的东西 |
| --- | --- |
| 射击 | `Fire()`；事件 `OnLocalFire`（枪口火焰、震屏）、`OnFireFX`（弹道、血花）、`OnHitConfirmed`（命中提示、击杀音效） |
| 血量 | `bIsEnemy`、`bIsElite`；事件 `OnHealthChanged`、`OnDeath` |
| 灵能 | `EquippedSpells`、`CastSpell(序号)`、`GetOverloadRatio()`（驱动低语音效和画面扭曲）；事件 `OnSpellCast`、`OnBacklash`（重度反噬时刷恶魔） |
| 撤离条件 | GameState 的 `Conditions`、`RevealNextHiddenCondition()`（线索物品被捡到时调用）、`AddConditionProgress()`；事件 `OnConditionsChanged` |
| 逃生舱 | 新建继承 `AbyssEscapePod` 的蓝图放进地图；零件拾取物重叠时调用 `AddPart`；玩家按键调用 Player Actions 的 `TryLaunchPod` |
| 回收装置 | Player Actions 的 `CallRecovery()`；GameState 事件 `OnRecoveryCalled`（放气球、刷敌人） |
| 地图生成 | 在 `BP_AbyssGameMode` 里实现 `BuildMapFromSeed`，生成的房间 Actor 要勾选 **Replicates** |
| 中途加入广播 | GameState 事件 `OnAnnouncement`；在 `BP_AbyssGameMode` 里把 `JoinMessageFormat` 改成中文，例如 `轨道空投信号已确认——{0} 降临战场。` |
